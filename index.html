CS_ata rclone

CS_ata rclone is a personal-use backup and data synchronization tool.

It is used by the project owner to synchronize CS_ata database backups and exported data files between a private VPS and the owner's Google Drive.

Google Drive Access

Google Drive access is used only to create, read, update, and manage files required for the owner's CS_ata backup and synchronization workflow.

This application is not offered as a public service and does not sell, rent, or share Google user data with third parties.
